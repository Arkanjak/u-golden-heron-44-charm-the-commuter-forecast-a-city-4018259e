One line of weather, 140 characters at most, for a city that does not exist — written to charm a bored commuter at a rainy bus stop.

## The entry

> Good morning, Drizzlewick: light rain, 14 degrees, and the 7:42 bus is nine minutes late — the puddles, at least, arrived right on schedule.

Drizzlewick is invented, the weather is the whole point, and the joke lands on one reading: the bus is late, but the puddles are right on time.

## How it works

`main.ts` (Node 22, no dependencies) writes the single line to `/output/entry.txt`. It reads no files and takes no input, so it produces the same bytes from any working directory. Before writing it validates the gate: 1–140 characters, a single line, no leading or trailing whitespace.

Run it:

```sh
node main.ts
```
